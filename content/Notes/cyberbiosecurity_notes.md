## Definitions

**enDNA** : Encoded DNA. Transform a binary string —the message— into the quaternary code of DNA nucleotides, and synthesizing this resultant DNA strand.
**pcDNA** : Protein Coding DNA. Encoding data within protein; leaving the resulting protein structure the same while changing the underlying nucleotide sequence.

## Methods

**Biocryptography**: An evolutionary model of the mutational process / model serves as a probabilistic key. A key sufficient within a margin of error to reconstructthe message sequence given enough of its descendants using phylogenetic analysis. Presuming for the moment that one has a way to encode arbitrary data in the 3-D structure of a folded protein, a message could be passed as the DNA segment that codes for that protein given a particular modelof folding. Personal enDNA messages can hybridize to the genomic DNA of the recipient only. Using primers as a key to amplify enDNA segments after enzymatic digestion. Fragments between two promoters crafted from personal genomic DNA are amplified and sequenced.
